# 왕왕랜드 색상 및 탐색 원칙

## 색상 기준

색상 정의는 `src/app/globals.css`에서 관리한다. 컴포넌트는 역할별 토큰을 사용한다.

| 역할 | 라이트 | 다크 | 사용 |
| --- | --- | --- | --- |
| 브랜드 오렌지 | #C66B43 | #C66B43 | 로고 기준색 |
| primary / brand-action | #B65532 | #EEA078 | 주요 행동 |
| brand-action-hover | #A94B2B | #F6B38E | 주요 행동 호버 |
| background | #FBF8F3 | #18191D | 페이지 |
| card | #FFFFFF | #2B2D34 | 카드 |
| foreground | #373A32 | #F2EFEB | 본문 |
| muted-foreground | #6F7068 | #B9B5B0 | 보조 설명 |
| accent | #FAEDE5 | #46332B | 선택 강조 배경 |
| secondary / muted | 기존 값 유지 | #363840 | 보조 영역·목록 헤더 |
| border | #E5DFD5 | #494C56 | 구분선 |

- 주요 버튼은 `primary`와 `primary-foreground`를 짝지어 사용한다.
- 브랜드 오렌지 자체에 흰색 작은 글자를 얹지 않는다. 버튼용 진한 색상을 사용한다.
- 관리자 메뉴는 라이트에서 기존 올리브·차콜, 다크에서는 중립 차콜 `#17181C`로 구분한다.
- 승인·경고·오류와 일정 유형 색상은 의미를 유지한다. 외부 서비스 고유색과 사용자 지정 일정 색상은 변경하지 않는다.
- 게시판 헤더는 동일한 중립 구분선을 사용한다. 주황색은 행동·선택 상태에 집중한다.

## 로고와 메뉴

- 정사각형 `SITE.logo`는 기존 프로필·앱용 로고로 유지한다.
- 가로형 `SITE.headerLogo`는 웹 헤더와 모바일 메뉴에 사용한다. PNG이며 벡터 원본이 아니다.
- PC 로고 260px, 모바일 180px. 다크모드는 `SITE.headerLogoDark`의 투명 PNG를 사용한다. 밝은 살구색 글자와 크림색 외곽선으로 배경판 없이 구분하며, 헤더와 모바일 메뉴 모두 `HeaderLogo`에서 전환한다.
- PC 헤더는 중앙 브랜드를 유지하고 오른쪽에 관리자 페이지(관리자·운영진만), 카카오톡, 네이버 카페, 인스타그램, 테마 전환 순으로 배치한다. 1280~1439px에서는 관리자·카카오톡 문구를 축약하고, 1280px 미만에서는 외부 바로가기를 햄버거 메뉴 안에서 제공한다.
- PC 사이드바와 모바일 메뉴는 `HomeSidebar`를 재사용한다.
- 관리자 PC 사이드바와 모바일 햄버거는 `AdminMenuContent`를 공유한다. 관리 항목의 장식 아이콘 없이 분류명·들여쓰기·간격으로 구분하며, 홈처럼 은은한 호버와 얇은 현재 위치 표시를 사용한다. 관리자 전용 진한 배경은 유지한다. 프로필은 36px 사진·13px 닉네임과 줄바꿈을 적용하고 로그아웃은 메뉴 하단에 둔다. 권한별 메뉴와 처리 대기 알림은 유지한다.
- 메뉴는 소식·이야기, 아이들·입양, 봉사, 후원, 보호소 안내로 구분한다. 봉사 신청 주요 버튼은 봉사 분류에 두며 회원이 설정한 즐겨찾기는 보존한다.
- 로그인 프로필은 36px 사진과 13px 닉네임을 표시하고 마이페이지로 연결한다. 긴 닉네임은 말줄임 없이 줄바꿈하고 카드 높이가 늘어나도록 한다. 알림은 별도 버튼, 로그아웃은 메뉴 하단에 둔다.
- 모바일 하단 빠른 메뉴는 유지한다. 새 메뉴나 장식 이모지는 추가하지 않는다.
- 사이드메뉴 봉사 신청은 다른 메뉴와 동일한 기본 배경·호버·선택 스타일을 사용한다. 기본 상태에서는 포인트색 글씨에만 7초 주기로 은은한 빛을 주며, 호버·키보드 포커스·모션 줄이기 설정에서는 글씨 효과를 끈다.

## 작성자와 게시글 목록

- 작성자 배경·테두리는 사용하지 않는다. 회원은 본문색, 운영진·관리자는 `primary` 글자색을 사용한다. 보조기술에는 역할을 텍스트로 전달한다.
- 공개 게시판 목록은 `BoardListHeader`·`BoardListRow`를 공유한다. 조회수 제목과 숫자는 같은 열에서 가운데 정렬한다. 홈은 `HomePostHeader`·`HomePostRow`, 관리자 편집 목록은 `PostListRow`를 사용한다.
- 유형 → 제목 → 작성자 → 작성일 → 조회수의 한 줄 목록으로 표시한다. 제목과 작성자는 열 너비를 넘으면 말줄임하며 전체 내용은 링크의 접근성 이름과 툴팁으로 유지한다. 댓글 수는 1개 이상일 때만 제목 옆에 표시한다.
- 공개 목록에는 사진과 본문 미리보기를 표시하지 않는다. 고정·새 글·첨부 표시는 제목 옆에 유지한다.
- 홈에서는 이야기 영역을 전체 폭으로 두고 그 아래 공지사항·지출 내역을 1280px 이상에서 1:1로 나란히 배치한다. 그보다 좁은 화면에서는 세로로 쌓는다. PC는 48px 썸네일·유형 및 제목·작성자·작성일·조회수를 한 줄로 표시하며 요약은 생략한다. 이미지가 없어도 제목 시작 위치를 유지한다. 모바일은 썸네일·제목 아래 작성자·작성일·조회수를 한 줄로 표시하며, 이야기 → 공지사항 → 지출 내역 순서로 배치한다.
- 다크 배경 #18191D, 헤더·사이드바와 바깥 콘텐츠 영역 #202126, 안쪽 카드 #2B2D34, 팝업·호버 #363840으로 명도를 구분한다. 선택 상태만 #46332B를 사용한다.
