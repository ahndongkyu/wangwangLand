# 왕왕랜드 색상 및 탐색 원칙

## 색상 기준

색상 정의는 `src/app/globals.css`에서 관리한다. 컴포넌트는 역할별 토큰을 사용한다.

| 역할 | 라이트 | 다크 | 사용 |
| --- | --- | --- | --- |
| 브랜드 오렌지 | #C66B43 | #C66B43 | 로고 기준색 |
| primary / brand-action | #B65532 | #EAA077 | 주요 행동 |
| brand-action-hover | #A94B2B | #F4B48C | 주요 행동 호버 |
| background | #FBF8F3 | #242622 | 페이지 |
| card | #FFFFFF | #2E312B | 카드 |
| foreground | #373A32 | #F5F0E7 | 본문 |
| muted-foreground | #6F7068 | #BCBDB1 | 보조 설명 |
| accent / secondary | #FAEDE5 | #44352B | 연한 강조 배경 |
| border | #E5DFD5 | #4D5146 | 구분선 |

- 주요 버튼은 `primary`와 `primary-foreground`를 짝지어 사용한다.
- 브랜드 오렌지 자체에 흰색 작은 글자를 얹지 않는다. 버튼용 진한 색상을 사용한다.
- 관리자 메뉴는 `admin-nav` 계열 올리브·차콜 토큰으로 구분한다.
- 승인·경고·오류와 일정 유형 색상은 의미를 유지한다. 외부 서비스 고유색과 사용자 지정 일정 색상은 변경하지 않는다.
- 게시판 헤더는 동일한 중립 구분선을 사용한다. 주황색은 행동·선택 상태에 집중한다.

## 로고와 메뉴

- 정사각형 `SITE.logo`는 기존 프로필·앱용 로고로 유지한다.
- 가로형 `SITE.headerLogo`는 웹 헤더와 모바일 메뉴에 사용한다. PNG이며 벡터 원본이 아니다.
- PC 로고 260px, 모바일 180px. 다크모드에서는 밝은 바탕으로 원본 색상과 외곽선의 식별성을 확보한다.
- PC 헤더에는 브랜드·외부 바로가기·테마 전환만 표시한다.
- PC 사이드바와 모바일 메뉴는 `HomeSidebar`를 재사용한다.
- 즐겨찾기 아래 봉사 신청 주요 버튼을 두고 일반 메뉴의 중복 봉사 항목은 생략한다. 회원이 설정한 즐겨찾기는 보존한다.
- 모바일 하단 빠른 메뉴는 유지한다. 새 메뉴나 장식 이모지는 추가하지 않는다.
